# Mobile Sales Analysis Dashboard – Power BI

## Project Overview
The Mobile Sales Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI. The dashboard provides a comprehensive analysis of mobile phone sales performance, helping understand sales trends, customer purchasing behavior, brand performance, and payment preferences.

The project transforms sales data into meaningful visual insights through interactive charts, KPIs, maps, and filters.

## Key Performance Indicators (KPIs)
- **Total Sales:** 769M
- **Total Quantity Sold:** 19K
- **Total Transactions:** 4K
- **Average Sales:** 40K

## Dashboard Features
1. **Monthly Sales Analysis:** Tracks total quantity sold across different months.
2. **City-wise Sales Analysis:** Uses map visualization to identify sales distribution across cities.
3. **Brand-wise Sales Analysis:** Compares sales performance of Apple, Samsung, Vivo, OnePlus, and Xiaomi.
4. **Mobile Model Analysis:** Evaluates sales across different mobile models.
5. **Payment Method Analysis:** Analyzes transactions made through UPI, debit cards, credit cards, and cash.
6. **Customer Ratings Analysis:** Visualizes customer ratings to understand customer satisfaction.
7. **Day-wise Sales Analysis:** Identifies sales performance across different days of the week.
8. **Interactive Filters:** Provides monthly and brand-based filtering for dynamic data exploration.
